Проект вдохвлен идеями из книги "Джидайские техники", суть проекта организовать планирование дел особым образом для повышения эффективности    
Сначала пользователь не очень вдумчиво добавляет какие-то дела в инбокс (любые, что в голову придет  - все в инбокс)    
Потом пользователь для каждого дела вдумчиво определяет создать по этому делу проект, задачу, или ничего не создавать       
(на любой стадии проекта можно добавить новое дело в инбокс, оно рассортируется в следующем цикле)    
Когда все дела рассортированы, пользователю открывается окно проектов и он для каждого проекта вдумчиво придумывает задачи    
Далее пользователь вдумчиво решает какая задача из проекта пойдет в текущую волну выполнения (обязательно по одной задаче из каждого проекта)    
Когда пользователь подтверждает свой выбор на текущую волну, ему становится доступно только окно с кнопкой Выдать задачу    
Пользователь выполняет все задачи из текущей волны, после этого, если во время цикла добавилось дело в инбокс, то дальше переход к сортировке дел в инбоксе, иначе перход к окну проектов    
Проекты можно завершать, тогда проект и его задачи удалятся из окна проектов
Таким образом мы  дробим крупный проект на маленькие несложные задачи и продвигаемся по каждому проекту

**Бекенд для проекта** : https://github.com/cherniuta/todo-backend

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.
